**接口设计说明**

**1 接口返回规范**

**1.1 成功返回**

{
`  `"code": 0,
`  `"message": "操作成功",
`  `"data": {}
}

**1.2 失败返回**

{
`  `"code": 1,
`  `"message": "失败提示说明",
`  `"data": {}
}

字段说明：

|**字段**|**说明**|
| :-: | :-: |
|code|状态码（0成功，1失败）|
|message|返回提示信息|
|data|返回数据|

**统一接口命名规范**

接口命名统一遵循：

资源名使用单数
多单词使用 \_

示例：

weight\_record
food\_record
exercise\_record
weight\_trend

避免：

food-record   ❌
foodRecord    ❌
